# multimodal — зрение и слух

## vision.py — подробное описание изображения
CLI: `python vision.py /path/to/photo.jpg` → весь текст с картинки дословно
(меню, вывески, ценники, документы) + перевод + описание сцены.
Ключи берёт из `~/.openclaw/.env` (EXCASH_API_KEY / EXCASH_API_URL).
Модель задаётся в коде — поставьте ту, что у вашего провайдера реально видит
картинки (проверяйте замером, каталоги шлюзов плавают!).

## transcribe.py — каскад распознавания речи
`OGG/WAV → текст`: локальный GigaAM (если поднят) → Groq whisper → LLM-шлюз.
Подключение к OpenClaw — в config/openclaw.example.json
(`tools.media.audio.models`, обязателен плейсхолдер `{{MediaPath}}` в args!).

## Грабли, съеденные за вас
- Если у модели в конфиге OpenClaw не указан `"input": ["text","image"]`,
  картинка молча выбрасывается, а агент **выдумывает**, что «видит».
- Правило в AGENTS.md: «есть MediaPath, но нет описания — ты фото НЕ видишь».
