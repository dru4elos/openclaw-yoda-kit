# Правила проекта «italiano» для агентов

Репозиторий — память занятий итальянским владельца с Йодой. Ведут по очереди владелец, Йода (ассистент на
OpenClaw) и Claude. Состояние живёт в самом репозитории, а не в чьей-то памяти.

## Как здесь устроено
- `data/*.json`, `data/sessions.jsonl` — машинная память (карточки, правила, журнал). Меняется **только через
  `tools/it.py`**: он держит блокировку, сроки FSRS и пересобирает сводки.
- `PROGRESSO.md`, `FRASI.md`, `REGOLE.md`, `situazioni/*.md` — собираются `it.py render`, руками не править.
- `situazioni/catalogo.json` — каталог ситуаций. Правишь каталог — затем `python tools/it.py render`.
- Итальянские фразы — только проверенные: сомнение в норме → проверить по словарю/грамматике, а не угадывать.

## Коммиты
- **Данные и сводки** `it.py` коммитит и пушит **сам, прямо в `main`** (конец урока, конец повтора, настройки).
  Это журнал, а не код: ветки и PR здесь не нужны.
- **Код и каталог** (`tools/`, `situazioni/catalogo.json`, документы) — ветка `<агент>/<кратко>` и PR в `main`.
- Перед работой — `git pull`, `STATUS.md`. В конце сессии с кодом — обновить `STATUS.md`.
- Ключей, паролей и чужих персональных данных здесь нет и быть не должно.

## ИИ в проекте
Проект делается с ИИ-ассистентами; раздел «Как использовался ИИ» в README держим актуальным.
