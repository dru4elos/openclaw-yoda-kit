# italiano — итальянский с Йодой

Живой итальянский через ситуации: бар, рынок, аптека, вокзал, отель, конгресс. Йода играет продавца, бариста
или коллегу, ты отвечаешь по-итальянски. Ошибся — короткое правило и проверочные задания, пока не решишь два
подряд. Выученные фразы и правила копятся здесь и возвращаются в мягком вечернем повторе.

## Как заниматься

Пиши Йоде в Telegram обычными словами:

| Пишешь | Что будет |
|---|---|
| «давай итальянский» | Йода предложит следующую ситуацию и подтип, урок 5–15 минут |
| «урок итальянского: аптека» | урок по названной ситуации |
| «как сказать по-итальянски …» | ответ с фразой; захочешь — добавит её в повтор |
| «повтори итальянский» | повтор прямо сейчас |
| «повтор в 21:00», «по 8 фраз», «пауза на неделю» | настройка расписания |
| «что я выучил по итальянскому» | сводка прогресса |

**Вечерний повтор** — каждый день в 20:00 (по Москве), если есть фразы, которым пора. Йода спрашивает 3–5 штук
по одной. Вспомнил — фраза уходит дальше (через 2 дня, неделю, месяц); не вспомнил — разбор, правило,
задания, и фраза вернётся завтра. Ответить можно когда удобно; «не сегодня» — ничего не потеряется.

## Для Йоды и Claude

Порядок работы — в [AGENTS.md](AGENTS.md) и в скилле `italiano` у Йоды. Команды: `python tools/it.py --help`.
Интервалы повтора считает [FSRS](https://github.com/open-spaced-repetition/py-fsrs) (MIT) — тот же алгоритм,
что в Anki.

## Откуда идеи

- Урок от ситуации «я сейчас тут — как сказать», фразы «скажу / услышу» и подсказка по грамматике —
  из [Google Little Language Lessons](https://developers.googleblog.com/en/how-its-made-little-language-lessons-to-personalize-learning/)
  (Tiny Lesson) и промптов [aoilang/language-learning-prompts](https://github.com/aoilang/language-learning-prompts) (CC0).
- Ролевая игра «держи собеседника в сцене» — оттуда же (Role Play).
- Вечерний вопрос с разбором — из подборки «7 промптов для изучения языка» (Telegram, 25.04.2025).
- Уровень CEFR и обращение «tu/Lei» как отдельная настройка — по мотивам [dialekt](https://github.com/ccarvalho-eng/dialekt).
- «Ошибка → правило → задания, пока не решишь» — метод владельца.

## Как использовался ИИ

Репозиторий ведёт Йода (ассистент на OpenClaw); каркас, инструмент и каталог ситуаций собрал Claude по
постановке владельца. Итальянские фразы каталога проверены вручную; найденные на занятиях фразы помечены
отдельно.
