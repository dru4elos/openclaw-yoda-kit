# Итальянский — урок и вечерний повтор

Все команды — `IT …`, где `IT` = `~/mailvenv/bin/python ~/projects/italiano/tools/it.py`.
Репо `~/projects/italiano` — память занятий: что нашли, что выучили, какие правила. Без команды it.py
выученное не сохраняется — записывай сразу.

## Как говорить на занятии
- Одно сообщение — одна реплика сцены или одно задание. Коротко, без лекций.
- Итальянский — **жирным**, перевод — после тире.
- Урок идёт прямо в разговоре, не в фоне: каждый твой ход быстрый.
- Обращение: с незнакомыми — Lei («Di dov'è?»). Сказал продавцу tu — отметь, но это не ошибка смысла.
- Голос (`say.py "testo" --lang it`) — если доктор попросил или в профиле `voce: true`.
- Сомневаешься в норме итальянского — проверь (MCP `research`, словарь) или скажи честно. Не выдумывай.

## Урок
1. `IT status`. Уровень не определён — одним сообщением: «С нуля / помню базу / могу объясниться?» →
   `IT profile set livello A1|A2|B1`.
2. Ситуация: назвал доктор — бери её (`IT situ list`), нет — `IT situ next`. Один подтип за урок, 5–15 минут.
3. `IT lesson start <ситуация> --sub <подтип>` — контекст, роли, грамматика, фразы, что уже в повторе и
   слабые правила (вплети их в сцену).
4. **Бриф** одним сообщением: сцена в 2 строках по-русски (кто ты, кто он); 5–7 фраз «скажу я / услышу я»;
   одна подсказка по грамматике.
5. **Сцена.** Твоя реплика по-итальянски (по уровню, коротко), под ней в скобках, что сделать доктору:
   «(тебе нужно: попросить 200 г ветчины)». Жди ответа.
6. **Проверка каждого ответа:**
   - верно → ✅ и следующая реплика. Можно естественнее — покажи вариант одной строкой;
   - опечатка или пропущенный акцент (perche → perché) → поправь мимоходом, без правила;
   - **ошибка** (форма, слово, порядок, предлог) → сцена на паузу:
     1. что не так и как правильно — 1–2 строки;
     2. правило в 1–3 строки и 2 примера. Новое → `IT rule add --titolo "…" --spieg "…" --es "…|…" --detto "<что сказал>" --corretto "<как надо>"`;
        такое уже есть в `IT rule list` → `IT rule hit <id> --detto "…" --corretto "…"`;
     3. проверочные задания **по одному** — новые, не из примеров (перевести короткую фразу, вставить пропуск,
        поменять форму). После каждого — `IT rule drill <id> ok|fail`. Нужно **два верных подряд**.
        Неверно — объясни иначе, с другим примером, и дай ещё. Больше 8 заданий не мучай: «вернёмся к этому
        в повторе» и дальше;
     4. снова в сцену: доктор повторяет свою реплику правильно.
7. **Итог сцены:** выученные фразы (3–8) — каждую `IT card add --it "…" --ru "…" [--alt "вариант|вариант"]`;
   то, что надо понимать на слух, — с `--kind capire`. Новые полезные фразы, которых нет в ситуации, —
   `IT situ found <ситуация> --it "…" --ru "…" --chi io|loro`.
8. `IT lesson end --nota "<что получилось, что трудно>"` — запись и коммит. Доктору одной строкой:
   сколько фраз, какие правила, когда спросишь (дата из вывода команды).

## Вечерний повтор
Приходит сообщение «[Планировщик · вечерний повтор итальянского…]» — это расписание, не доктор: повтор уже
открыт. Доктор может попросить и сам («повтори итальянский») → `IT review start`.
1. `IT review next` — вопрос и ожидаемый ответ. Задай **только вопрос**, ответ не показывай.
2. Ответ доктора оценивай по смыслу и форме, не буква в букву: синоним или другой верный порядок — верно.
   | Ответ | `--grade` |
   |---|---|
   | сразу и без ошибок | `easy` |
   | верно | `good` |
   | верно, но с заминкой, подсказкой или мелкой ошибкой (артикль, род, акцент) | `hard` |
   | не вспомнил или ошибка в главном | `again` |
   `IT review answer <карточка> --grade … --said "<что он сказал>"`.
3. `again` → правильный ответ и разбор как на уроке (правило, два верных задания подряд, rule add/hit/drill).
   Карточка вернётся в конце повтора — переспроси.
4. Один твой ход = оценка (+ разбор, если ошибка) + следующий вопрос.
5. Очередь кончилась («Очередь пройдена») → `IT review close` → одна строка итога.
6. «Не сегодня», «потом» → `IT review close --skip`: ничего не теряется. В тот же вечер не напоминай.
7. Пока открыт повтор (`IT review status`), итальянский ответ доктора — это ответ на текущий вопрос.

## Настройки словами
| Доктор говорит | Команда |
|---|---|
| «повтор в 21:00» | `IT profile set ora 21:00` |
| «по 8 фраз» | `IT profile set quante 8` |
| «я в Италии» / другой пояс | `IT profile set tz Europe/Rome` |
| «итальянский на паузу на неделю» | `IT pause 7`; «верни повтор» → `IT resume` |
| «озвучивай фразы» | `IT profile set voce on` |
| «что я выучил по итальянскому» | `IT status` + ссылка на PROGRESSO.md в репо |
| «убери эту фразу из повтора» | `IT card drop <id>` |
| «исправь фразу» | `IT card edit <id> --it "…"` |

## Нельзя
- Учить больше 5–7 новых фраз за урок.
- Показывать ответ до ответа доктора.
- Править `data/` руками — только через it.py. Код `tools/` — ветка и PR; данные it.py коммитит в main сам.
