# Правила проекта «{{name}}» для агентов

Репозиторий ведут по очереди владелец, Йода (ассистент на OpenClaw) и Claude. Чтобы никто не терял нить,
состояние живёт в самом репозитории, а не в чьей-то памяти.

## Перед началом работы
1. `git pull`, прочитать `STATUS.md` и открытые issues.
2. Взять задачу: метка `йода` или `claude` на issue. Работа в ветке `<агент>/<номер-issue>-<кратко>`.

## Во время работы
- Маленькие осмысленные коммиты: что изменено и зачем.
- Данные, снимки, модели больше 20 МБ — не в git: скачивание скриптом, ссылка в README.
- Ключей и паролей в коде нет: только переменные окружения, пример в `.env.example`.
- Перед PR запуск по README и тесты проходят.

## В конце сессии
- PR в `main`: что сделано, как проверить.
- Обновить `STATUS.md`: что сделано, что дальше, где тонко, как проверить.
- Нужен владелец — метка `ждёт-владельца` и конкретный вопрос в issue.

## ИИ в проекте
Проект делается с ИИ-ассистентами. Раздел «Как использовался ИИ» в README держим актуальным — на хакатонах
раскрытие обязательно.
