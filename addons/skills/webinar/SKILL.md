# webinar — эфир под ключ, без импровизации

Запрос вида «запишись на вебинар/конференцию, подтверди всё, поприсутствуй сам, запиши и
сделай подробный конспект» — это ЭТОТ скилл. Не собирай контур руками из кронов и
`exec`: один вызов `plan` ставит всё, финиш идёт командным кроном без агента.

```
P=~/mailvenv/bin/python; W=~/.openclaw/workspace/skills/webinar/webinar.py
$P $W plan --title "Название" --url "<ссылка на трансляцию>" --start "09.09 19:00" --end "21:00" \
           [--register-url "<где регистрируются>"] [--focus "что особенно важно владельцу"]
$P $W status --out <папка>            # что уже сделано
$P $W finish --out <папка>            # обработать запись вручную (идемпотентно)
$P $W selftest --minutes 6            # проверка контура на куске прошлой записи (НЕ во время эфира)
```

Время — МСК. `plan` создаёт папку `~/.openclaw/workspace/Эфиры/<дата>_<slug>/` с `plan.json` и
четыре крона на агенте `background` (изолированные сессии, отчёт владельцу в Telegram):

| когда | что | кто |
|---|---|---|
| сейчас +2 мин (если задан `--register-url`) | регистрация и подтверждение | агент |
| начало −10 мин | вход в комнату в профиле `rec`, `webrec start --until конец+10`, `unmute`, `probe` | агент |
| начало +20 мин | контроль: `webrec status` + `probe`, при тишине `unmute`, при падении — `start` заново | агент |
| конец +12 мин | **финиш**: стоп → громкость → GigaAM v3 по кускам 10 мин → чистка → конспект → отправка | команда, без агента |

## Регистрация («подтверди всё») — что делать агенту
1. Форма на сайте — браузер с профилем по умолчанию (`openclaw`, невидимый). Данные владельца
   из `USER.md`: имя, e-mail, телефон, город, специальность. Заполняй только обязательные поля,
   лишних подписок не ставь. Оплата, капча, «подтвердите по SMS» — стоп, доложи владельцу.
2. Письмо-подтверждение: `mail.py` (поиск по отправителю/теме за последние 15 мин), ссылку
   подтверждения открой в браузере. Из письма возьми ссылку на трансляцию и время — положи в
   `plan.json` (`url`) или сразу вызови `plan`.
3. Регистрация через Telegram-бота организатора или личный кабинет — за владельца нажать
   нельзя. Отправь ему ссылку одной строкой и попроси переслать ссылку на трансляцию.
4. В календарь: `cal.py add "…" --start "YYYY-MM-DD HH:MM" --dur N --confirm yes`.
5. Итог — одной строкой: где зарегистрирован, что подтверждено, чего не хватает.

## Как устроен финиш (чтобы не переделывать руками)
- Видео: `<slug>_full.mp4` из сегментов webrec. Средняя громкость ≤ −70 дБ → «немая запись»,
  расшифровки нет, владельцу честный отчёт.
- Расшифровка: звук → WAV 16 кГц моно → куски по 10 мин → контейнер GigaAM v3
  (`gigaam-v3-e2e-rnnt`, `127.0.0.1:8001`), 3 попытки на кусок, резерв — Gemini через excash.
  Сырая версия — `transcript_raw.md`.
- Чистка огрехов ASR: каждый кусок через `gemini-3.8-flash` с хвостом предыдущего для
  связности: термины, имена, числа, пунктуация, абзацы, реплики; факты не трогает,
  непонятное — `[неразборчиво]`. Итог — `transcript.md` с таймкодами.
- Конспект: вся стенограмма одним запросом в `gpt-6-astra-1m` (1M контекста) по жёсткой
  структуре — `summary.md`. Резерв: sol-1m, gemini-3.8-flash.
- Доставка: сообщение владельцу + `summary.md` + `transcript.md` через Bot API. Видео остаётся
  на сервере (путь в сообщении).
- Всё в `state.json`: повторный `finish` доделывает только недостающее. Журнал — `pipeline.log`.

## Грабли
- Профиль браузера для эфира — только `rec`; в профиле по умолчанию запись будет пустой.
- `webrec selftest` и `webinar selftest` — не во время эфира.
- Конца эфира агент не ждёт и не поллирует — это стоило 942k токенов и сорванного отчёта.
- Запись уже есть на диске (прислали файл, скачали запись организатора)? Положи её как
  `<имя>_full.mp4` в папку и вызови `finish --out <папка> --title "…"`.
