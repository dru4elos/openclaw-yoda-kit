МАКЕТЫ ТЕМЫ sci — ставятся комментарием <!-- _class: имя --> первой строкой слайда

  title           титул: <h1> + <div class="meta">автор<br>место<br>дата</div>
  air             мало текста, кегль сам крупнее (24 pt) — для 3-4 тезисов
  dense           много данных, кегль 18 pt — для таблиц
  statement       одна крупная фраза по центру + <div class="sub">уточнение</div>
  section-break   бордовый разделитель между частями доклада
  figure-right    текст слева, иллюстрация справа   ← рабочая лошадь доклада
  figure-left     зеркально
  figure-full     иллюстрация во весь слайд + <div class="caption">подпись</div>
  two-figures     две картинки рядом: «до / после», сравнение методик
  quote           цитата или реплика пациента

ЭЛЕМЕНТЫ

  <p class="kicker">Результаты · n = 148</p>   служебное имя раздела: мелко,
                                               полупрозрачно, НАД утверждением
  <span class="rule"></span>                   короткая бордовая линейка
  <div class="bignum">82%</div>                когда весь смысл — в одном числе
  <div class="src">Источник: ...</div>         сноска внизу, 13 pt
  <figcaption>Рис. 1. ...</figcaption>         подпись под иллюстрацией

КОЛОНКИ (для figure-right / figure-left / two-figures)

  <div class="cols">
  <div class="txt">

  текст

  </div>
  <div class="fig">

  ![](рисунок.png)

  </div>
  </div>

  Пустые строки вокруг markdown внутри <div> обязательны — иначе он
  не разберётся и приедет сырым html.

ГРАБЛИ

  • SVG молча не рендерится в PDF/PNG — только PNG/JPG
  • внешние ссылки на картинки не подгружаются — файл должен лежать рядом
  • кегли менять в themes/sci.css (:root), а не инлайном в слайде
