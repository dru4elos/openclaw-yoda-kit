# deck — научные презентации

Метод **assertion-evidence** (M. Alley, Penn State). Проверен в исследованиях:
аудитория запоминала материал достоверно лучше (p < .01), а сами докладчики
глубже понимали свою тему, когда готовили слайды так.

Суть: **заголовок слайда — предложение с главной мыслью**, под ним визуальное
доказательство. Не «РЕЗУЛЬТАТЫ», а «82% вернулись в спорт за 3 месяца».

## Команды

```
python3 ~/.openclaw/workspace/skills/deck/deck.py new доклад.md \
        --title "..." --author "Семенов А. В., к.м.н." --affil "..." --date "2026"
python3 .../deck.py layouts                 # шпаргалка по макетам
python3 .../deck.py check доклад.md --vision  # ОБЯЗАТЕЛЬНО перед выдачей
python3 .../deck.py render доклад.md --to pdf   # pdf | pptx | png | html
```

## Железные правила слайда

1. **Один слайд — одна мысль.** Нюансы допустимы, вторая тема — нет.
2. **Заголовок несёт мысль, а не имя раздела.** 8–14 слов, максимум две строки.
   Служебное имя («Результаты», «Методы») уходит в кикер — мелко и полупрозрачно
   НАД заголовком. Проверка `check` заворачивает ярлыки списком.
3. **Доказательство визуальное.** У каждого содержательного слайда —
   иллюстрация, схема, график или таблица. Слайд из одного текста
   допустим только как `statement` (одна крупная фраза).
4. **Меньше текста на слайде — больше в устной речи.** Предел: 45 слов,
   30 для `air`, 70 для таблиц. Буллетов не больше пяти, вложенных нет.
5. **Кегли трогать только в `themes/sci.css`.** Заголовок 28 pt, тело 18–24 pt
   (класс сам подберёт), источники 13 pt. Инлайновый `font-size` в слайде —
   признак, что содержание не влезло: сокращай текст, а не шрифт.
6. **Есть цифра — есть источник.** Строкой `<div class="src">`.

## Иллюстрации

Своих картинок нет — рисуй скиллом `imggen` (Grok Imagine 2) и клади рядом
с .md. Схемы удобнее собирать HTML+CSS и снимать в PNG.

- **SVG молча не рендерится** в PDF/PNG — только PNG/JPG.
- **Внешние ссылки не подгружаются** — файл должен лежать рядом с .md.
- Медицинские снимки пациентов — только обезличенные.

## Проверка — не пропускать

`check --vision` делает три вещи: читает разметку (ярлыки, перегруз, битые
картинки), меряет рендер по пикселям (перелив за поля, пустой или забитый
слайд) и **смотрит на каждый слайд глазами** через `vision.py`.

Стоп-замечания чинить до показа: это либо сломанный слайд, либо ярлык вместо
мысли. Правки — на усмотрение, но обосновать.

Никогда не докладывай «готово», не прогнав `check`.

## Что отдавать доктору

`--to pdf` для проектора (шрифты вшиты, ничего не съедет на чужой машине),
`--to pptx` когда организаторы требуют PowerPoint, `--to png` для соцсетей.
Файл слать через `tome.py file`.
