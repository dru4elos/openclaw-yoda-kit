# deck — научные презентации (Marp + assertion-evidence)

Слайд пишется в markdown, вёрстку держит тема: кегли, поля и место под
иллюстрацию заданы в CSS, поэтому испортить их содержанием нельзя.

Метод — **assertion-evidence** (M. Alley, Penn State): заголовок слайда это
предложение с главной мыслью, под ним визуальное доказательство, а не буллеты.
В исследованиях Penn State аудитория запоминала такой материал достоверно
лучше (p < .01). Не «РЕЗУЛЬТАТЫ», а «82% вернулись в спорт за 3 месяца»;
служебное имя раздела уходит в кикер — мелко и полупрозрачно над заголовком.

## Установка

```bash
# Node 24 (через nvm) + браузер + LibreOffice для editable pptx
npm install -g @marp-team/marp-cli
sudo apt install -y chromium libreoffice-impress   # или snap install chromium

cp -r deck ~/.openclaw/workspace/skills/
```

Скилл зовёт `~/.openclaw/vision.py` (см. аддон `vision`) для проверки слайдов
глазами. Без него работают разметочные и пиксельные проверки.

## Как пользоваться

```bash
python3 deck.py new доклад.md --title "..." --author "..." --affil "..." --date "2026"
python3 deck.py layouts                    # шпаргалка по макетам
python3 deck.py check доклад.md --vision   # перед показом — обязательно
python3 deck.py render доклад.md --to pdf  # pdf | pptx | png | html
```

`check` делает три прохода: читает разметку (ярлык вместо мысли, перегруз,
битые картинки), меряет рендер по пикселям (перелив за поля, пустой или
забитый слайд) и смотрит на каждый слайд моделью зрения.

## Грабли, которые мы уже собрали

- **SVG молча не рендерится** в PDF/PNG — только PNG/JPG.
- **Внешние ссылки на картинки не подгружаются** — файл кладите рядом с .md,
  и обязателен флаг `--allow-local-files` (в `deck.py` он уже есть).
- **Шрифты вшиты в CSS base64.** Marp инлайнит тему в html, и относительный
  путь ищется от папки доклада, а не от темы — текст молча уезжал в запасной
  шрифт. Исходные TTF лежат в `fonts/`.
- **Брать полные TTF, а не woff2 из Google css2**: первый блок там
  `cyrillic-ext` — 127 глифов, русских букв в нём НЕТ.
- **snap-хромиуму нужен `CHROME_NO_SANDBOX=true`**, иначе рендер виснет.
- **Картинка в flex-колонке** без `min-height: 0` растягивает колонку под свой
  натуральный размер и уезжает за нижний край вместе с подписью.

## Смена оформления

Цвета и кегли — в `themes/sci.css`, блок `:root`. Заголовок 28 pt, тело
18–24 pt, источники 13 pt — это правила метода, менять осознанно.
Свои шрифты: положите TTF в `fonts/` и перевшейте base64 в `@font-face`.
