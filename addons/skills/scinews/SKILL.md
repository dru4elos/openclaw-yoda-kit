# Научные статьи: поиск и полный Word-разбор

Запуск: `~/mailvenv/bin/python ~/.openclaw/workspace/skills/scinews/sci.py ...`

- Поиск:            `search "pediatric ACL reconstruction" --n 8`
- **Word-разбор:**  `word "<запрос или PMID/DOI>" --send`  (или `--pmid 123` / `--doi 10.x/y`)
- **Разбор из PDF доктора:** `word --pdf /путь/к/файлу.pdf --send`

## Полный текст статьи
Скрипт сам пытается достать ПОЛНЫЙ текст (а не только абстракт), по порядку:
1. Europe PMC (PMC XML) для Open Access;
2. OpenAlex → открытые версии по DOI;
3. Unpaywall → открытые версии (в т.ч. авторские рукописи в репозиториях);
4. Semantic Scholar → openAccessPdf.
Работаем только с легальными открытыми источниками. Если открытой версии нет — разбор
честно делается по абстракту, и это указывается в документе (не выдумывай содержание!).

## Если статья платная
Скажи доктору: если у него есть доступ (подписка, библиотека РНИМУ, институциональный доступ) —
пусть пришлёт PDF в чат, и ты сделаешь полный разбор командой `word --pdf <файл> --send`.
Присланные файлы Йода видит в `~/.openclaw/workspace/media/inbound/`.

## Как использовать
- «Найди статьи про X» → `search`.
- «Разбери статью / сделай подробный разбор» → `word ... --send` (полный документ, не дайджест).
- Доктор прислал PDF статьи → `word --pdf <путь> --send`.

## Автоматические научные алерты
На сервере крутится `science_monitor` — он следит за научными рассылками в Gmail
(Google Scholar и т.п.), разбирает статьи через excash и **шлёт алерты прямо в твой чат
с доктором** (раньше они приходили от DATA_bot — доктора это раздражало).
Ты их не запускаешь: они приходят сами. Если доктор спросит «что там по науке» —
используй `search`/`word` этого скилла, а не жди алерта.
