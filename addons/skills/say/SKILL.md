# Голос: ответить владельцу голосовым

```
<python venv> ~/.openclaw/workspace/skills/say/say.py "текст"            # язык определится по тексту
<python venv> ~/.openclaw/workspace/skills/say/say.py "testo" --lang it  # итальянский (голос paola)
<python venv> ~/.openclaw/workspace/skills/say/say.py "текст" --lang ru  # русский (голос dmitri)
```
Длинный текст: `--file /tmp/answer.txt`. Только сгенерировать файл: `--keep`. Что установлено: `--voices`.
Синтез локальный (piper), интернет не нужен, стоит 0 ₽. Резерв — edge-tts, если стоит в venv.

## Когда отвечать голосом
**Только когда владелец явно попросил**: «скажи голосом», «озвучь», «ответь голосовым», «по-итальянски
голосом». Попросил общаться голосом на итальянском — отвечай голосовыми с `--lang it`, пока не скажет
иначе. По умолчанию — текст, даже если он прислал голосовое. Встроенный инструмент `tts` не использовать.

## Как говорить
- Голос ≠ текст. Пиши для уха: короткие фразы, без списков, markdown и ссылок. Числа словами там,
  где так естественнее.
- Держись 30–60 секунд (примерно 400–800 символов). Длинное — текстом, голосом — выжимку.
- Таблицы, код, реквизиты — только текстом.
