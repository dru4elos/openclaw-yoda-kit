# Голос: ответить доктору голосовым

`~/mailvenv/bin/python ~/.openclaw/workspace/skills/say/say.py "текст"`
Длинный текст: `--file /tmp/answer.txt`. Только сгенерировать файл: `--keep`.

Синтез локальный (piper, русский мужской голос), интернет не нужен, стоит 0 ₽.

## Когда отвечать голосом
**ТОЛЬКО когда доктор явно попросил**: «скажи голосом», «озвучь», «наговори», «голосом».
По умолчанию — всегда ТЕКСТ, даже если он прислал голосовое сообщение.
Сам инициативу не проявляй: непрошеное голосовое раздражает.

## Как говорить
- Голос ≠ текст. Пиши для УХА: короткие фразы, без списков, без markdown, без ссылок
  (скрипт их вырежет, но лучше сразу не вставлять). Числа словами там, где так естественнее.
- Держись 30-60 секунд (примерно 400-800 символов). Длинную аналитику голосом не читай —
  отправь текстом, а голосом дай выжимку.
- Таблицы, код, списки препаратов, реквизиты — ТОЛЬКО текстом, голос для них не годится.
