# Глубокое исследование — hyperresearch

Запуск (всегда в фоне, разговор не блокирует):
`~/.openclaw/workspace/skills/hyperresearch/hr.sh start "<вопрос словами доктора>" [--light|--full] [--model sol|astra]`

- Вопрос передавай **дословно**, как сказал доктор: пайплайн считает его «священным текстом» и
  строит план от точной формулировки. Уточнения доктора допиши в конец той же строкой.
- `--light` — «быстро», «обзорно», «коротко»: ~30–40 мин, 5 шагов.
- `--full` — «глубоко», «по-взрослому», «со всей доказательной базой»: ~1,5–2,5 ч, 16 шагов
  с критиками и проверкой цитат. Без ключа пайплайн выбирает сам по вопросу.
- `--model astra` — только если доктор попросил «астрой» или тема тяжёлая; по умолчанию Sol.

В чат после запуска — одна строка из вывода `hr.sh` и всё. Прогресс по шагам виден в живой
полоске («Глубокое исследование: …»), готовый отчёт уходит доктору файлом сам. Ты его не пересылаешь.

## Когда брать, а когда нет

| Задача | Что брать |
|---|---|
| Клинический вопрос врача — лечение, диагностика, обзор литературы по болезни | ДокМед (основной медицинский движок) |
| Широкий вопрос вне ДокМеда: рынок, конкуренты, технологии, регуляторика, поездка, сравнение продуктов | **hyperresearch** |
| Доктор прямо сказал «хайперрисерч» / «глубокое исследование» | **hyperresearch**, даже если тема медицинская |
| Быстрый факт, одна-две ссылки | сама, без пайплайна |

## Остальное

- Что идёт и что готово: `hr.sh status`. Остановить: `hr.sh stop <id>`.
- Одновременно идёт одно исследование. Второе — после первого.
- Все прочитанные источники копятся в хранилище `~/projects/research/research/` и работают
  на следующие исследования: `~/hr-venv/bin/hyperresearch search "<тема>"` ищет по уже собранному.
- Данные пациентов в вопрос не клади: поиск идёт через внешние сервисы.
