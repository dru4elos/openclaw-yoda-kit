# Документы: прочитать и проверить своими глазами

`~/mailvenv/bin/python ~/.openclaw/workspace/skills/docs/docs.py <команда>`

- **Прочитать:** `read <файл>` — весь текст (docx, pptx по слайдам с заметками, xlsx по листам, pdf, txt, odt/odp).
  Так ты читаешь и присланные доктором документы.
- **Проверить перед отправкой:** `check <файл>` — текст + классификация КАЖДОЙ картинки внутри
  (SAFE / NUDITY / GORE) и вывод «документ чистый» или «отправлять нельзя».
- **Посмотреть глазами:** `preview <файл> [--pages 12] [--send] [--no-vision]` — отрисовывает страницы или
  слайды (LibreOffice → PDF → PNG), описывает зрением, что реально видно (включая обрезанный и наезжающий
  текст), и **оставляет PNG в `~/.openclaw/workspace/media/preview/<имя>/`** — открывай их `view_image`,
  чтобы проверить вёрстку своими глазами. В /tmp `view_image` не смотрит. `--send` пришлёт картинки доктору.

## ЖЕЛЕЗНОЕ ПРАВИЛО
**Любой документ с картинками, который ты собрал, ПЕРЕД отправкой доктору прогоняй через `check`.**
Нашлась хоть одна проблемная — пересобери без неё и проверь снова. Не отправляй «на авось».

Так однажды в документ про отели попали две эротические картинки и куча мусора не по теме
(манга, зубная нить, спорткар) — потому что картинки брались из открытых банков без проверки.
Теперь скилл `images` фильтрует каждую картинку зрением, а `docs check` — последний рубеж.

Если доктор сомневается в готовом документе — `preview --send`: он увидит страницы как есть.

## Презентации и таблицы
PPTX/XLSX правь библиотеками из `~/mailvenv` (`python-pptx`, `openpyxl`) — никаких venv в /tmp. После правок обязательно
`preview` и посмотри слайды, где менял текст: переполнение блоков видно только глазами. Один файл правит один
исполнитель: субагенту отдал — сам не трогай, поправки передавай ему.
