# События Москвы (афиша на ближайшие 3 дня)

Запуск: `sudo /root/tradebot/events/yoda_events.sh`

- Возвращает JSON с подобранными событиями (выставки, активный отдых, необычные места, еда)
  под профиль пары, на ближайшие 3 дня. Источники: KudaGo API + Afisha.ru.
- Прогон занимает ~1–2 минуты (собирает данные и прогоняет через LLM) — предупреди доктора,
  что «собираю афишу».

## Как использовать
- «Что интересного в Москве на выходные / куда сходить» → запусти скрипт, разбери JSON
  (`top_events`), и выдай доктору топ-5–8: название, суть в одну строку, место, цена, дата.
- Если доктор просит — можешь оформить списком и отправить ему (обычным сообщением).
- Отдельный cron сам шлёт красивый PDF-отчёт паре по расписанию; этот скилл — для подбора по запросу.
- Данные реальные (из источников); не выдумывай события.
