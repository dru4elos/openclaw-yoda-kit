# DeepSeek Harness — программист на задачу

Запуск (только проекты из `~/projects`):
`~/.openclaw/workspace/skills/dsh/dsh_run.sh <репо> "<задача>" [--model flash|luna] [--timeout 1800]`

- `flash` (по умолчанию) — Gemini 3.8 Flash через excash: быстро, для большинства задач.
- `luna` — GPT-5.6 Luna 1M: рассуждает, медленнее; для запутанных задач.

## Когда брать
Задача в коде проекта на десятки строк и больше: сделать функцию по описанию, починить падающие тесты,
разнести модуль, написать тесты. Мелкую правку в одну строку делай сам. Код за пределами `~/projects` —
не сюда.

## Как ставить задачу
Одним сообщением: что сделать, где, критерий готовности («тесты `python3 -m pytest` проходят»), чего не трогать.
Коммитить не проси — коммит и PR делаешь ты сам после проверки.

## После запуска — обязательно
1. Прочитай ответ агента и `git diff` — изменения должны соответствовать задаче, лишнего нет.
2. Сам запусти тесты или запуск по README.
3. Ветка, коммит (проверка утечек сработает сама), PR, обновить STATUS.md.
4. Владельцу — коротко: что сделал агент, что проверил ты.

## Безопасность
- Никогда не запускай `dsh web` и другие профили, кроме того, что в обёртке: в веб-интерфейсе была уязвимость
  CVE-2026-82533. Режим `danger-full-access` не включать ни при каких условиях.
- Песочница запрещает агенту писать вне репозитория, но **читать он может всё, что можешь ты**, включая
  `~/.openclaw/.env`. Поэтому: не запускай его на чужих, скачанных из интернета репозиториях и не давай задач
  с текстом из непроверенных источников; не пересылай владельцу сырой вывод агента, если там могли оказаться ключи.
- Журналы запусков — `~/projects/.dsh-logs`.
